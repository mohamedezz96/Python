# Palindromes Checker

## Lab 2.5.7

This project implements a program to **check whether a given text is a palindrome**.  
A palindrome is a word, phrase, or sequence of characters that reads the same **forward and backward**.  

**Examples:**
- "kayak" → palindrome  
- "loyal" → not a palindrome

---

## Problem Description

The program should:

1. Ask the user to enter a text string
2. Ignore case differences (treat uppercase and lowercase letters as equal)
3. Ignore spaces during the check
4. Determine whether the entered text is a palindrome
5. Print the result

**Notes:**
- An empty string is **not considered a palindrome**
- Spaces should be treated as non-existent
- There are multiple correct ways to implement the check

---

## Input and Output

### Input
- Any string entered by the user

### Output
- Message stating whether the string is a palindrome or not
