# 3.4.10 LAB – Triangle

This lab demonstrates how to embed one class inside another by using objects of the `Point` class to define a `Triangle`.

## Objectives

- Use the existing `Point` class
- Create a `Triangle` class that:
  - Accepts three `Point` objects
  - Stores them in a **private list**
  - Calculates the **perimeter** of the triangle
