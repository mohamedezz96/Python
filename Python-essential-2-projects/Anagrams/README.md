# Anagrams Checker

## Lab 2.5.8

This project implements a program to **check whether two texts are anagrams**.  
An anagram is formed by rearranging the letters of a word or phrase using all the original letters exactly once.  

**Examples:**
- "rail safety" ↔ "fairy tales" → anagrams  
- "I am" ↔ "You are" → not anagrams

---

## Problem Description

The program should:

1. Ask the user to enter two separate texts
2. Ignore case differences (treat uppercase and lowercase letters as equal)
3. Ignore spaces when checking (treat them as non-existent)
4. Determine whether the two texts are anagrams
5. Print the result

**Notes:**
- Two empty strings are **not considered anagrams**
- Spaces should be ignored
- There are multiple correct ways to implement the check

---

## Input and Output

### Input
- Two strings entered by the user

### Output
- Message stating whether the texts are anagrams or not
